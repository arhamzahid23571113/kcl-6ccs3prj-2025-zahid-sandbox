\section{Introduction}
\label{sec:introduction}

Modern image classifiers can achieve high benchmark accuracy while remaining unexpectedly vulnerable to carefully chosen perturbations.
A small change to the input can be sufficient to change a confident correct prediction into a confident incorrect one, even when the perturbed image appears visually similar to the original \cite{szegedy2014intriguing,goodfellow2015explaining}.
This matters both scientifically and practically.
Scientifically, adversarial examples reveal that high predictive accuracy does not imply a stable or semantically robust decision boundary.
Practically, they show that machine-learning systems can fail in ways that are difficult to anticipate from aggregate accuracy metrics alone.

Within this broader literature, the one-pixel attack is especially striking.
Rather than allowing a diffuse perturbation across many coordinates, it restricts the attacker to modifying only a single spatial location in the image \cite{su2019onepixel}.
At first sight, this threat model may appear too narrow to matter.
However, it is precisely this narrowness that makes the setting valuable.
If a classifier can be changed by altering a single pixel, then the resulting adversarial example exposes a particularly sharp form of local instability.
At the same time, the one-pixel setting is experimentally attractive because it yields a compact black-box optimisation problem in a low-dimensional search space.
That makes it possible to study not only whether attacks succeed, but also how different search strategies and evaluation perspectives interact.

A second reason the one-pixel setting is useful is that it provides a controlled context in which to study post-hoc explanations.
Explanation methods such as Grad-CAM, Integrated Gradients, and RISE are widely used to visualise which parts of an image appear influential for a model prediction \cite{selvaraju2017gradcam,sundararajan2017ig,petsiuk2018rise}.
Yet the explanation literature has also shown that such methods can be noisy, fragile, or misleading if interpreted uncritically \cite{adebayo2018sanity,alvarezmelis2018robustness,ghorbani2019fragile}.
A successful one-pixel adversarial example is therefore interesting for more than attack success alone.
It provides a compact test case for asking whether the explanation attached to a prediction remains stable when the model is moved across a decision boundary by an extremely sparse perturbation.

This project studies black-box one-pixel attacks on CIFAR-10 \cite{krizhevsky2009cifar} using Differential Evolution (DE) as the optimisation backbone \cite{storn1997de}.
The work focuses on two linked questions.
The first concerns explanation robustness: how explanation maps change when the attack succeeds.
The second concerns guided attack design: whether a responsibility-map prior can improve one-pixel search in a useful sense.
The responsibility map is estimated using RISE, which is itself a black-box explanation method \cite{petsiuk2018rise}.
This is important because it keeps the guidance mechanism aligned with the black-box constraints of the attack.
The project therefore studies adversarial effectiveness, query cost, and explanation behaviour within a single reproducible evaluation framework.

\subsection{Motivation and problem context}
The project is motivated by a gap between three strands of literature that are often discussed separately.
The adversarial machine-learning literature has established that neural networks are vulnerable to carefully designed perturbations \cite{goodfellow2015explaining,madry2018towards}.
The black-box attack literature has shown that many of these vulnerabilities remain relevant even when gradients or model parameters are unavailable \cite{papernot2017practical,chen2017zoo,brendel2018decision}.
The explainable-AI literature has shown that post-hoc explanation methods can themselves be unstable or fragile under input changes \cite{adebayo2018sanity,ghorbani2019fragile,dombrowski2019explanations}.

What is less often studied in an integrated way is the interaction between these strands in a tightly controlled sparse-budget setting.
A one-pixel black-box attack is small enough to be interpretable and large enough to be meaningful.
It allows the report to ask not only whether an attack can be made to work, but also what kind of successful cases it produces and how those successful cases affect explanation behaviour.
This makes the project more than a reproduction of an established attack.
It becomes a comparative study of sparse adversarial success, explanation robustness, and guidance trade-offs.

\subsection{Research questions}
The report is organised around two research questions:

\begin{itemize}
  \item \textbf{RQ1:} How do successful one-pixel attacks affect explanations?
  \item \textbf{RQ2:} Can responsibility-map guidance improve one-pixel attacks?
\end{itemize}

RQ1 concerns the stability and faithfulness of explanations under successful attack.
RQ2 concerns the usefulness of explanation-derived guidance as a spatial prior for sparse black-box search.
Together, the two questions allow the report to examine both the \emph{outcomes} of one-pixel attacks and the \emph{quality} of the procedures used to obtain those outcomes.

\subsection{Contributions}
The main contributions of the project are as follows:
\begin{itemize}
  \item A reproducible 10k-scale study of black-box one-pixel attacks on CIFAR-10 using a fixed pretrained classifier and a fixed eligible image subset.
  \item A comparative evaluation of three attack configurations: an untargeted DE baseline, a fixed-budget fastprior multi-target variant, and a responsibility-map-guided DE variant.
  \item A systematic analysis of explanation behaviour on successful adversarial examples using three explanation methods---Grad-CAM, Integrated Gradients, and RISE---and three quantitative measures: IoU@10, Spearman rank correlation, and deletion AUC.
  \item A frozen results pack and report-oriented artefact pipeline in which final tables, plots, and summaries are generated from stable CSV artefacts rather than copied manually.
\end{itemize}

These contributions are deliberately bounded.
The project does not claim to introduce a state-of-the-art black-box attack or a new explanation method.
Its contribution is instead the integrated and auditable evaluation of sparse attack success, query cost, and explanation behaviour within one controlled framework.
