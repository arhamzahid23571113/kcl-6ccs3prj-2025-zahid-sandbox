\section{Introduction}
\label{sec:introduction}

Adversarial examples demonstrate that modern image classifiers can be highly sensitive to carefully chosen perturbations.
Even when the change to the input is very small, the model can produce a confidently incorrect prediction.
This matters both scientifically, because it reveals properties of learned decision boundaries, and practically, because it exposes robustness risks in deployed machine learning systems.

A particularly striking case is the \emph{one-pixel attack}, in which the adversary is restricted to modifying only a single pixel in the image \cite{su2019onepixel}.
Although this perturbation budget is extremely small, the setting remains useful for two reasons.
First, it provides a clean and interpretable black-box optimisation problem in a low-dimensional search space.
Second, it offers a controlled way to study how post-hoc explanations behave when a classifier is changed from a correct to an incorrect decision by a minimal but successful perturbation.

This project studies one-pixel attacks on CIFAR-10 \cite{krizhevsky2009cifar} under a black-box threat model, using Differential Evolution (DE) as the optimisation backbone \cite{storn1997de}.
Beyond attack success alone, the project evaluates the behaviour of three widely used explanation methods---Grad-CAM \cite{selvaraju2017gradcam}, Integrated Gradients (IG) \cite{sundararajan2017ig}, and RISE \cite{petsiuk2018rise}---under successful one-pixel adversarial perturbations.
The report therefore addresses both adversarial effectiveness and explanation robustness in a single experimental framework.

\subsection{Research questions}
\textbf{RQ1:} How do successful one-pixel attacks affect explanations? \\
\textbf{RQ2:} Can responsibility-map guidance improve one-pixel attacks?

\subsection{Contributions}
The main contributions of the project are as follows:
\begin{itemize}
  \item A reproducible 10k-scale study of black-box one-pixel attacks on CIFAR-10, covering an untargeted DE baseline, a fixed-budget fastprior multi-target variant, and a responsibility-map-guided DE variant.
  \item A systematic analysis of explanation behaviour under successful adversarial perturbations using three explanation methods and three quantitative measures: IoU@10, Spearman rank correlation, and deletion AUC.
  \item A report-ready experimental artefact pipeline, including frozen CSV outputs, comparison summaries, generated plots, and imported \LaTeX{} tables, so that the numbers reported in the final evaluation are traceable to fixed source artefacts.
\end{itemize}
